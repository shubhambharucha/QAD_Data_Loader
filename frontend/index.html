How it works

Precision at
every step.

The loader connects to your FastAPI backend over SSE, streaming file-by-file results as operations run — no polling, no timeouts, no guessing.

01
Select entities
Choose which of the 10 data types to process. Cards show live file counts polled every 5 seconds from your backend.
02
Validate or load
Validate checks file integrity. Load executes. Both stream SSE results in real time and support operations that run for hours.
03
Live feedback
Pass = green. Fail = red. The results table fills row by row as events arrive from the stream.
04
Archive & retry
Clean files are archived automatically. Error files are prefixed and flagged for re-run.
