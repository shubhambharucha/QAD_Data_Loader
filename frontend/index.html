How it works

Precision
at every
step.

The loader connects directly to your FastAPI backend over SSE, streaming results file-by-file as operations run — no polling, no timeouts, no guessing.

01
Select entities
Choose which of the 10 data types to process. Cards animate on selection, showing live file counts polled every 5 seconds from your backend.
02
Validate or load
Hit Validate to check file integrity, or Load to execute. Both stream SSE results in real time — operations run for 30 minutes or more without a timeout.
03
Live visual feedback
Pass = green left bar. Fail = red. If any entity fails, the entire bar cluster surges red. The results table fills row by row as events arrive.
04
Auto archive & retry
Successful files are archived automatically. Error files get prefixed and flagged. Select only the failed entities and re-run.
